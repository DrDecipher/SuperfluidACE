

We will impliment start up logic to give the user the ability to select what type of session they would like to engage in.

Start Up List:
0. Cont Last Session
1. Work on Feature
2. Start New Feature
3. Just Code


Continue Last Session: Start where the last session left off by loading the most recent context.
Work On Feature: Provide a list of existing features. in a new selection dialog let the user select a feature to resume
Start New Feature: Launch our wizard for building a new feature
Just Code: Exit to the the promt input doing nothing.
