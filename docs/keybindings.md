# Codex CLI Keyboard Shortcuts

> **Added 2025-06-19** – Home/End + Shift variants

Shortcut | Action
--- | ---
Home | Move caret to beginning of current line
End | Move caret to end of current line
Shift + Home | Select from caret to line start
Shift + End | Select from caret to line end

These keys complement the existing arrow-key navigation and word-wise shortcuts. Selection can be copied with the standard Copy (`Alt+C` / platform shortcut) once implemented.
